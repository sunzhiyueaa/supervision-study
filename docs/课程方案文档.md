# 高中生卷面提分练字体系（五阶素材库）

> **小程序复用说明**  
> 1. 所有 `[　]` 代表一个田字格/米字格，`________` 代表横线格。  
> 2. 每课的 `示范字` 可单独提取作为字帖图片生成源。

## 阶段一：控笔与基本笔画（8课）

**目标**：纠正握笔，稳定手部肌肉，掌握8种核心笔画的轻重变化。

### 第1课：长横与短横
**书写要点**：长横起笔稍顿，行笔轻快，收笔加重，整体呈左低右高之势，弧度为微微上拱。短横用力均匀，写得短促饱满。
**示范字**：一、二、三
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第2课：悬针竖与垂露竖
**书写要点**：悬针竖尾巴出尖，书写时要缓缓提笔；垂露竖收笔回锋，尾部圆润如露珠。二者都要写得挺拔正直。
**示范字**：十、干、丰
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第3课：斜撇与竖撇
**书写要点**：斜撇要写得舒展，起笔重，由重到轻快速撇出，末尾出锋。竖撇先竖后撇，如“月”字撇。
**示范字**：人、左、月
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第4课：斜捺与平捺
**书写要点**：捺画一波三折，轻起笔，向右下渐行渐重，至捺脚处稍顿，再水平向右出锋。平捺见于“之”字，角度更平。
**示范字**：大、之、这
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第5课：竖钩与弯钩
**书写要点**：竖钩在竖画末端向左上快速钩出，钩不宜过大。弯钩多用于反犬旁，弯中求正，重心要稳。
**示范字**：小、可、狂
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第6课：横折与竖折
**书写要点**：横折的转折处需顿笔，形成方肩。竖折则是竖画结束后笔不离纸，向右行笔写横，转折处圆转中带方。
**示范字**：口、山、区
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第7课：提画与点画
**书写要点**：提画重起轻收，迅速向右上方挑出。点画虽小，要有起笔、行笔、收笔动作，写出饱满的“三角一肚”。
**示范字**：冷、江、照
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第8课：复合笔画的连贯
**书写要点**：横撇、横折钩、竖折折钩等复合笔画，讲究转折处的提按过渡。不能生硬停顿，要气息连贯。
**示范字**：又、九、弓
**练习**：

## 阶段二：高频偏旁部首（10课）

**目标**：掌握常见偏旁，让字的结构“稳”下来。重点解决偏旁与主体部分的搭配。

### 第9课：单人旁与双人旁
**书写要点**：单人旁撇画稍斜，竖画起笔在撇的中部。双人旁两撇指向不同，第二撇起笔偏左，竖画对准第二撇中间。
**示范字**：仁、休、行、德
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第10课：三点水与言字旁
**书写要点**：三点水呈弧形排列，第二点稍左，上两点间距小，下提点呼应右部。言字旁横折提要注意折角顿笔，整体偏窄。
**示范字**：河、海、说、话
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第11课：木字旁与禾木旁
**书写要点**：作为偏旁时横画左伸右缩，捺变为点，以让右。竖画要垂直穿过横画偏右位置。
**示范字**：林、松、和、程
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第12课：草字头与竹字头
**书写要点**：草字头两竖上开下合，横画被两竖三等分。竹字头左右同形，但左小右大，撇点呼应。
**示范字**：花、草、笑、答
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第13课：宝盖头与穴宝盖
**书写要点**：首点居中，左点与横钩要断开，横钩的钩指向下一个字。穴宝盖下面的“八”要内收。
**示范字**：安、宝、空、穿
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第14课：走之底与建之旁
**书写要点**：走之底的点与下部的横折折撇距离要小，捺画伸展托住上方。建之旁第一笔横折折撇要内收，捺画稍平。
**示范字**：过、道、廷、建
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第15课：心字底与皿字底
**书写要点**：心字底卧钩要写出弧度，钩尖指向中心，三点呼应。皿字底横长托上，两侧竖画内收。
**示范字**：思、想、孟、盘
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第16课：反文旁与欠字旁
**书写要点**：反文旁撇横要收敛，第三笔撇画稍弯曲，捺画舒展。欠字旁上紧下松，下部“人”要支撑有力。
**示范字**：故、教、歌、欢
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第17课：月字旁与舟字旁
**书写要点**：月字旁要写得窄而高，里面的两横不与右竖连死。舟字旁同理，注意做偏旁时横不出头过长。
**示范字**：明、服、船、般
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第18课：衣补旁与示补旁
**书写要点**：这两个偏旁极易混淆。示补旁右边是一点，衣补旁是两点。书写时都要注意点、横撇的断开与呼应。
**示范字**：祖、礼、被、袜
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

## 阶段三：间架结构黄金法则（10课）

**目标**：学会观察字的“骨架”，脱离格子也能写整齐。每课精讲一种结构规律。

### 第19课：横平竖直
**要点**：横不是绝对水平，而是7-10度上斜；竖画在任何位置都要垂直，支撑字形。
**示范字**：书、章、申、华
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第20课：主笔突出
**要点**：每个字都有一个最舒展的笔画，要放开写；其他笔画适当收紧。
**示范字**：成（斜钩）、武（斜钩）、春（撇捺）、千（长横）
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第21课：上紧下松
**要点**：上部笔画紧凑，下部笔画疏朗，重心在上，字形才挺拔。
**示范字**：是、走、方、秀
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第22课：左紧右松
**要点**：左右结构，通常左边要收紧，右边要放展，左让右。
**示范字**：林、从、北、比
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第23课：内紧外松
**要点**：包围或半包围结构，内部要紧凑，外框要稳健，外框的大小决定字的大小。
**示范字**：国、画、幽、周
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第24课：多横等距
**要点**：字内有多个横画时，间距大致相等，且长短参差，切忌雷同。
**示范字**：其、直、星、善
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第25课：点竖直对
**要点**：上下结构的字，上部的点与下部的竖画应在一条中线上，重心才能对齐。
**示范字**：永、家、常、安
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第26课：裙不落地
**要点**：上下结构，当上部有撇捺时，下部的部件要往上靠，不能脱节。
**示范字**：金、食、今、全
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第27课：借让避就
**要点**：部件之间要注意穿插，一笔画可稍微伸入对方空白区域，使字更紧密。
**示范字**：妙、难、秋、鸦
**练习**：

### 第28课：同形相并
**要点**：左右同形，左小右大；上下同形，上小下大。相同部件要有变化。
**示范字**：竹、朋、吕、昌

## 阶段四：高考易错高频字实战（5课，共50字）

**目标**：消灭卷面“字迹潦草”的源头——结构易散、笔画易糊的字。每课10字，逐一攻破。

### 第29课：易糊字训练（一）
**练习字**：餐、勇、蠢、鼻、察、幽、繁、赢、瓣、辩
**指导**：这些字笔画多，关键在于“均分空间，主笔突出”。例如“餐”的撇捺要舒展，“鼻”的上部要紧缩。
**练习**：

### 第30课：易倒字训练（二）
**练习字**：家、象、夜、夏、卷、苍、昏、黎、攀、碧
**指导**：重心不稳的字，要多检查撇捺的交叉点是否与竖中线重合，底部支撑点是否到位。
**练习**：
[　] [　] [　] [　] [　] [　] [　] [　] [　] [　]

### 第31课：易窄字训练（三）
**练习字**：骨、周、风、凤、鼠、舅、戴、裁、武、式
**指导**：斜钩和竖弯钩是难点，卧钩和斜钩一定要写出曲度，骨字框和风字框要挺拔。
**练习**：

### 第32课：易分家字训练（四）
**练习字**：知、和、唯、明、鸿、雅、版、即、却、即
**指导**：左右结构切勿分太开，左旁的末笔要写短，右旁的第一笔尽量向左穿插。
**练习**：

### 第33课：易写长字训练（五）

## 阶段五：实用篇章书写（名言+诗词）

**目标**：从单字过渡到词句、段落，解决字间距、行气和整篇布局问题。建议用横线格或空白格练习。
