# 学习监督小程序 - 整体设计文档

## 1. 项目概述

**项目名称**：学习监督（supervision-study）

**项目简介**：一款面向高中生的学习监督微信小程序，主要功能为练字打卡监督和错题记录管理。由于用户的弟弟没有手机，与妈妈共用同一部手机和同一个微信号，因此采用**统一界面设计**，不区分家长端和学生端角色。

**目标用户**：
- 主要使用者：高中生（练字打卡、错题记录）
- 监督者：家长（通过同一账号查看记录、设置提醒）

**核心功能**：
1. **练字打卡**：每日上传练字照片，AI评分反馈
2. **错题本**：记录和管理各科错题
3. **日历记录**：可视化查看打卡历史和统计
4. **积分奖励**：打卡获得积分，激励坚持
5. **字帖生成**：选择素材文章生成字帖
6. **提醒设置**：订阅消息定时提醒练字

### 2.2 可迁移设计原则

服务层 `services/api.js` 采用统一API调用设计：

- 当前使用**微信云开发**（`config.env = 'cloud'`），通过 `wx.cloud.callFunction` 调用云函数
- 后续可切换为**独立后端**（`config.env = 'server'`），通过 `wx.request` 调用 HTTP API
- 切换只需修改 `config` 配置，业务代码无需变动

```
callAPI(name, data)
  ├─ cloud: wx.cloud.callFunction({ name, data })
  └─ server: wx.request({ url: baseUrl/api/name, data })
```

### 3.3 首页设计

- **顶部**：绿色渐变卡片，显示今日日期和连续打卡天数
- **中间**：今日任务卡片（练字打卡状态、错题本状态），点击直接跳转
- **下方**：本周完成情况的小日历条（7天打卡圆点）
- **底部**：快捷功能入口（字帖素材、我的字帖、积分奖励、设置）

| 集合名 | 用途 |

## 5. 云函数列表

| 云函数 | 功能说明 |
|--------|---------|
| login | 用户登录注册（获取openid，查询或创建用户） |

| generateCopybook | 生成字帖（根据文章和选项生成字帖图片） |

## 6. 技术选型说明

### 6.1 百度AI OCR

- 用于识别手写练字图片中的文字
- 使用百度OCR手写文字识别API
- 密钥存储在云函数环境变量中，避免前端暴露
- 当前接口框架已预留，需配置API Key后激活

### 6.2 微信订阅消息

- 用于每日定时提醒练字
- 需在微信公众平台申请模板消息
- 用户需主动订阅才能收到推送
- 通过云函数 `sendReminder` 批量发送

### 6.3 字帖生成

- 根据文章素材和用户选择的字体/格子类型生成字帖图片
- 当前接口框架已预留
- 可选方案：Canvas服务端绘制 / 第三方API

### 6.4 积分体系

| 行为 | 积分 |
|------|------|
| 每日练字打卡 | +10 分 |
| 字体评分80分以上 | +5 分 |
| 记录错题 | +3 分 |
| 连续打卡7天 | +30 分（额外奖励） |
